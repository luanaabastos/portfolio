# Arquivo legado: redessociais.html

Arquivado de forma reversível no Checkpoint G em 13 de agosto de 2026.

## Motivo

A página apresentava posicionamento profissional antigo e conflitante com o
portfólio atual, além de canonical divergente, links desatualizados, IDs
duplicados e uma referência JavaScript ausente.

Não havia links internos apontando para ela, referência no sitemap nem uso de
seus três ativos exclusivos pelo `index.html` atual.

## Conteúdo preservado

- `redessociais.html`;
- `assets/css/stylesociais.css`;
- `assets/js/svg-inject.min.js`;
- `icons8-programação-96.png`.

Os caminhos relativos foram mantidos. O diretório `_archive` é ignorado pela
publicação Jekyll padrão do GitHub Pages. Caso a hospedagem seja substituída por
outro pipeline, `_archive` deve ser excluído explicitamente.

Para restaurar, mova os quatro arquivos de volta às suas localizações originais.
